# JuegoJoseph - Aprendo Jugando

Juego didáctico para niñas y niños de **3 años en adelante**.

## Incluye
- 🔤 Abecedario (letra + ejemplo)
- 🎵 Vocales
- 🔢 Números del 1 al 10
- 🇬🇧 Inglés básico (palabras simples)
- 🎲 Modo aleatorio
- 🧠 Mini reto por categoría
- 🔊 Lectura en voz alta usando `speechSynthesis`

## Cómo ejecutarlo
Como es una app estática, puedes abrir `index.html` directamente o levantar un servidor local:

```bash
python3 -m http.server 8000
```

Luego visita: `http://localhost:8000`
