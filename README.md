# JuegoJoseph

Juego didáctico web para niños de 3 años en adelante.

## ¿Qué incluye?

- Abecedario completo (incluye Ñ) con ejemplos.
- Vocales con palabras de apoyo.
- Números del 1 al 10.
- Vocabulario básico en inglés (palabra en inglés + traducción).
- Dos mini juegos:
  - Identificar vocales.
  - Contar objetos.

## Cómo ejecutar

Como es una app estática, puedes abrir `index.html` directamente o ejecutar un servidor local:

```bash
python3 -m http.server 8000
```

Luego abre: `http://localhost:8000`.
